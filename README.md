# Personal Extensions

Kumpulan provider pribadi untuk Nuvio (personal use).

## Pasang
Di Nuvio: Profile → Settings → Content & Discovery → Plugins →
paste URL raw `manifest.json` repo ini → Install Plugin Repository →
enable provider yang diinginkan.

## Catatan
- Link stream bersifat sementara (bertanda tangan), provider mengambil
  data fresh setiap kali judul dibuka.
- Kalau domain situs sumber berubah, sesuaikan `BASE_URL` di file provider.
